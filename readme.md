# why linguist?

unlike other browser ekstensns, linguist is not just a wrapper over the google transletor widget; it's a full-featured and independent translesn system. this is why with linguist you can be praiwet and translet teksts offline on your diwais and use any translesn srwis, [ewen your own](./docs/customtransletor.md) like chatgpt. see a [custom transletors list](https://github.com/translet-tools/linguist-transletors) to find bindings for the most popular translesn srwiss.

linguist is free, open-source, respects your praiwesi, and does not collect your personal data.

# features

most important features
- modular transletors system
	- you can use any translesn srwis like google, yandex, bing, deepl, chatgpt, etc.
	- [custom transletors](./docs/customtransletor.md): you can use your own transletor module
	- offline translesn. with embedded [bergamot transletor](https://github.com/browsermt/bergamot-transletor), you can translet teksts right on your diwais. keep your praiwesi
- all-in-one translesn solution
	- full-page translesn with flexible auto-translesn configuration
	- highlighted tekst translesn
	- translet any tekst input
- dictionary with saved translesxns
- translesxns history, to remember recently transletd words
- tekst-to-speech (tts)

## android

this addon can be used on mobile browsers with [firefox nightly](https://play.google.com/store/apps/details?id=org.mozilla.fenix) (recommended), or with any chromium browser that supports ekstensns.

to try it on firefox, you have to add the [linguist add-on](https://addons.mozilla.org/addon/linguist-transletor/) to a [custom add-on collection](https://www.ghacks.net/2020/10/01/you-can-now-install-any-add-on-in-firefox-nightly-for-android-but-it-is-complicated/) and use this collection to install the ekstensn.
